Deviations from the boards, and why

  • S15 Add sheet keeps two working rows the board does not list, Upload a photo and Describe your meal, in the same row style. Removing them would remove existing entry points.
  • S18 AI Support has no recipe-draft card yet: the coach service only proposes weekly schedules, so the draft card is a program draft with Review program draft opening the existing add flow. A recipe proposal tool would be a server change that cannot be verified here.
  • S19 Welcome shows Continue with Apple only on builds that ship that native module, as before; the board's Sign in opens the email code flow.
  • S20 Units converts weight everywhere (Overview, Health, measurements, weekly review, the reading form). Circumferences and machine-report masses stay in cm and kg; the preference note says only the display changes.
  • S29 Search food searches your history and recipe library. Public catalogue search needs a server proxy to the Open Food Facts text-search endpoint, which is not connected; the screen says so rather than pretending.
